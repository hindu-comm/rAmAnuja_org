Sri:

One can find several of these and other related
mantras in mahAnArAyanOpanishad. There are mantras
in there that are to be recited while getting into
water prior to snAnam, while bathing (hiryaNashrugam..), 
using mud (bhUmi) for cleansing purposes etc.. 
Interestingly, there is only a partial listing of 
sandhya vandana mantras in this upanishad.
(sUryascha maa manyuscha.. etc). Why would an upanishad
contain only partial listing, if it dealt with
the daily rituals ? (pATha-bhEdam not withstanding)
