Dear Devotees,

Please note that Sri Tridandi Chinna Jeeyar Swamiji's web site has 
been updated. Please visit the URL, http://www.chinnajeeyar.org.

Features:

1. Sri Swamiji was gracious enough to bless us with His Sri Sookthis
   through TeleUpanyasam in English. Details and Signup
   information for Sri Swamiji's TeleUpanyasam on 27th January, 
   2001(Last Saturday of this month) are available on the web site.

2. Sri Godha Ranganatha Kalyanam pictures.
   (Click on Thiruppavai Celebrations link)

3. For Telugu readers, Sri Swamiji's New Year 2001 message in 
   pdf format.

4. Information about Bheeshma Ekadasi Celebrations in Washington,
   DC, USA.

Please revisit the site for more exciting things happening in the
future. If you have any questions, comments please feel free to 
drop us an email.
