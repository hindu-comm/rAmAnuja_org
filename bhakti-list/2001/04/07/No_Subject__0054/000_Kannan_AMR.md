Dear Bhagavadhothamas:
Please visit http://www.srivaishnavam.org/ to view the latest Serthi Sevai of SriRangam Dhivyadhampathigal. My sincere thanks to my friend S.R.Raghunathan, The Hindu, for sending this wonderful picture. A short note about this web site. This web site is under construction. This web site will contain information about all the 108 Dhivyadesams and also many useful tourist information (such as food, accommodation etc,.). Also we planned to offer online Sandhai of Nalayira DhivyaPrabhandhams. And later we may add Sandhais for Swamy Desikan's Prabhandhams & Slokams and Swamy Manavalamamunigal's Dhivya SriSookthis. Hopefully we expect PART of this project to be ready by Chithirayil Seyya Thiruvadhirai. And the images which you will see in this web site will be originals. Except for certain Dhivyadesams (such as Malayala Dhivyadesams and Vadadesa Sthalams) we will be using all the origianl pictures either taken by me or by my friends. But all these things will be updated only by Chithirai Thiruvadhirai. As far as this serthi picture is concerned, you can download, print or put it in your web site. No copyrights regulations are applied for all the SriVaishnavas. But no digital manipulation of facts please.  
RamanujaDasan
Kannan
