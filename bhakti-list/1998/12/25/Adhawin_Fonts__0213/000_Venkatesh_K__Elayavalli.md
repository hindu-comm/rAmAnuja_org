Dear Members,

The Unix BDF fonts for Adhawin can now be downloaded from

http://www.SriVaishnava.org/adhawin.tgz

I would like to thank Dr. K. Srinivasan of California for providing
the TTF source.

This is a tarred gziped file. Please follow the instructions in the
to extract the fonts

------------

1. Save the file from the above link.

2. to extract the fonts. type the following command at
    the Unix prompt line

    gunzip -c -d  | tar xf -

    This will create a directory 'Adhawin' in the directory where
     you executed the above command.

Both Adhawin and Mylai fonts are included in this tar file. The
Readme file describes on how to install the fonts for Netscape.
(ps. I have not tested this for Internet Explorer for Unix)
