Dear BhakthAs of Sri Godhai :

In this posting , we will perform Naama KusumAnjali
for Our ThAyAr on her birth day thru the words of
Swami Desikan himself . The students of GodhA shtuthi
woud be familiar with the meanings of the rich Sanskritic
Text of Swami Desikan's eulogy :

1.(praNavam ) VishNuchittha Kulanandhana Kalpavallyai nama:
2.(   "     ) Sri RangarAja Harichandana yukthAyai nama:
3.(   "     ) SaakshAth KshamAyai nama:
4.(   "     ) KamalA sadhrusAya nama:
5.(   "     ) Jananyai nama:
6.(   "     ) KrishNAnvayaya nama:
7.(   "     ) Devyai nama:
8.(   "     ) TanthrI ninAdha madhura vachAya nama:
9.(   "     ) Mouli dhAmnA Bhagavantham niyamithAya nama:
10.(  "     ) adharE sONa varnAya nama:
11.(  "     ) kuchayO: tunga BhadhrAya nama:
12.(  "     ) VaachAm PravaahE Sarasvathyai nama:
13.(  "     ) aprAkruthai: rasayA VirajA samAnAya nama:
14 (   "    ) SvabhAvAth GodhAyai nama:
15.(   "    ) Kamithu: NarmAdhAyai nama:
16.(   "    ) Visva UpajeevyAyai nama:
17.(   "    ) VachasA amrutha dhuhAnAyai nama:
18.(   "    ) Hima ruchE: anya rUpAya nama:
19.(   "    ) PayOdhi Duhithu: sahajAya nama:
20.(   "    ) GodhAvari Punitha KaaraNAya nama:
21.(   "    ) SuthanavE nama:
22.(   "    ) NaagEsa dEvyai nama:
23.(   "    ) Pakshiratha dEvyai nama:
24.(   "    ) PurANa Purusha dEvyai nama:
25.(   "    ) Isvaryai nama:
26.(   "    ) Rangapathi: soubhAgya DhAyinE nama:
27.(   "    ) sarva gandhAthi adhigandha surabhI krutha chAru Moulyai nama:
28.(   "    ) RangEsvarasya PrANa Naayakyai nama:
29.(   "    ) VishNu chitthAthmajAyai nama:

There are 29 slOkams in Swami Desikan"s GodhA sthuthi.
Hence we will conclude this salutation to Sri Godhai
with 29 Naama KusumAnjalis .

SrimathE GodhA samEtha Sri RanganAthAya nama;
Daasan , Oppiliappan koil Varadachari Sadagopan
