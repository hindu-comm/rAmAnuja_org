Dear Sri Mani,

I would like to echo on the thoughts provided by the member as below.
In fact I still remember the date July 3rd 1998 when I joined this 
list and from there I have learnt a lot. I have learned many useful 
things, seen many arguments and indulged in them myself too, and the 
feelings that I got was diverse. However, the knowledge that I earned 
was great. 

But while, restructuring the list, when you created 3 sub lists, the 
number of the messages in the Bhakti list got reduced. Also as one 
member aptly stated, the revised form of Bhakti list is too much (in 
the sense that it makes it possible for only the highly knowledgeable 
persons to write in it). So the common man like me who have something 
to say cannot say anything (may be some silly arguments too!!). This 
can be viewed from the groups homepage wherein, there is very steep 
downfall of the messages after the restructuring was announced by 
you. Nevertheless, if you combine the number of postings in each 
group (i.e, bhakti, sv-general, sv-ritual and sv-poetry), then it is 
the original average message per month. 

This itself proves that there is no low w.r.t to the activities in 
the Bhakti list. However, you have to visualize the Bhakti list as 
the main one with the other 3 as the sub levels. But if you see 
Bhakti list as a separate list, then yes, certainly the activity has 
come down and the reason for this is as stated above. 

I am not so knowledgeable person to advise you on how to change this 
settings. You know it better yourself. So please do the needful as 
you feel.

BUT THE STANDING POINT IS THAT, THERE CAN BE NO LULL IN THE BHAKTI 
LIST AND THERE IS NO NEED FOR YOU TO EVEN THINK ABOUT CLOSING IT DOWN.

adiyEn rAmAnuja dAsan
