This is a list of Sanskrit terms for days, months, etc. This info. is
from a Lifco publication (Nityaanushtaanakramam).

As I am transliterating(?) from Tamizh, some sounds may be wrong. Corrections
are welcome. Apologies for the heavy Tamizh bias (to non-Tamizh members).

Key : s* as in Shankar
      sh as in Pushpam
      n  = na-2 or na-3 in Tamizh
      N  = na-1 in Tamizh

1. Ayana's
   Tai to Aani       : Uttaraayanam
   Aadi to Maargazhi : Dakshinaayanam

2. Rtu's (seasons)
   Chittirai, Vaigaasi   : Vasanta rtu  
   Aani, Aadi            : Greeshma rtu
   AavaNi, Purattaasi    : Varsha rtu
   Aippasi, Kaarththigai : Sharat rtu
   Maargazhi, Tai        : Hemanta rtu
   Maasi, Panguni        : Shishira rtu

3. Months
   Chittirai (mid April to mid May) : Mesha             (maase)
   Vaigaasi                         : Rishabha
   Aani                             : Mithuna
   Aadi                             : Kataka
   AavaNi                           : Simha
   Purattaasi                       : Kanyaa
   Aippasi                          : Tulaa
   Kaarththigai                     : Viruchchika
   Maargazhi                        : Saapa          ?? (Sagittarius?)
   Tai                              : Makara 
   Maasi                            : Kumba
   Panguni                          : Meena

4. Paksha's (phases of the moon)
   Pratamai (after Amaavaasya) to Paurnami : Shukla paksham (bright phase)
   Pratamai (after Paurnami) to Amaavaasya : Krihna paksham (dark phase)

5. Vaaram's (days of week)
   Sunday    : Baanu (vaasara yuktaayaam)
   Monday    : Indu
   Tuesday   : Bauma (Pauma?)
   Wednesday : Sowmya
   Thursday  : Guru
   Friday    : Brghu
   Saturday  : Sththira
