This is a much delayed response to Vaidehi's request
for a list of names for Lord Vishnu.  The following is
a partial list of some wonderful Tamil names collected
from the Little Flower publication of the Dhivya
Prabhandam.  Names such as azhagiya maNavaaLar,
meyyappan, and viLakkoLi perumaaL are very pleasing
to the ear as well as the mind.

--  Dileepan
